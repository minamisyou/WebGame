# GRAVITON — 모바일 웹 게임 기획서

> 한 손 엄지로 즐기는 **회전 중력 머지 퍼즐**. 설치 없이 브라우저에서 바로, 한 판 90초.

- 문서 버전: v1.0 (2026-08-14)
- 대상 플랫폼: 모바일 웹 (iOS Safari 16+, Chrome/Android 10+, Samsung Internet)
- 개발 규모: 1인 기준 약 4~5주
- **구현 상태: M0~M5 구현 완료.** 실행 방법과 코드 구조는 [README](../README.md) 참고.
  마일스톤 대비 남은 항목은 [8장](#8-개발-마일스톤-1인-기준) 아래 표기.

## 1. 왜 이 장르인가

모바일 웹은 네이티브 앱과 제약이 다릅니다. 기획은 이 제약에서 출발했습니다.

| 모바일 웹 제약 | 기획 대응 |
| --- | --- |
| 설치 없이 링크로 유입 → 첫 10초에 이탈 | 로딩 3초 이내, 튜토리얼 없이 첫 판 시작 |
| 입력이 터치 하나, 한 손 조작이 많음 | 조작 = 탭 + 좌우 스와이프 **2가지뿐** |
| 저사양 안드로이드 비중이 큼 | 물리엔진·3D 없음. 격자 기반 결정론적 로직 + Canvas 2D |
| 지하철/엘리베이터 등 네트워크 불안정 | 완전 오프라인 동작(PWA). 서버는 랭킹에만 선택적으로 사용 |
| 세션이 짧고 자주 끊김 | 1판 60~120초, 언제든 일시정지·복구 |
| 정밀 타이밍 입력에 불리(터치 지연, 프레임 튐) | 실시간 반사신경 대신 **턴제 퍼즐**. 지연에 영향받지 않음 |

→ **결론: 턴제 격자 퍼즐**이 모바일 웹에 가장 안전하면서, 훅만 좋으면 리텐션이 높은 장르.

### 대안으로 검토했던 후보

| 후보 | 장점 | 탈락 이유 |
| --- | --- | --- |
| 원터치 엔들리스 러너 | 학습 비용 0, 바이럴 | 프레임 드랍/터치 지연에 직결 → 저사양 기기에서 체감 품질 붕괴 |
| 수박게임류 물리 머지 | 검증된 중독성 | 물리 시뮬레이션 비용 + 기기별 결정론 깨짐 → 데일리 랭킹 불가 |
| 실시간 1:1 대전 | 리텐션 최상 | 서버·매칭·치팅 대응 필요, 1인 4주 범위 밖 |

## 2. 게임 개요

**GRAVITON** (국문 표기: 그래비톤)

7×7 격자에 숫자 오브를 떨어뜨려 같은 숫자 3개 이상을 붙여 합치는 퍼즐. 여기에 **보드 전체를 90° 회전시키는** 고유 능력이 붙습니다. 회전하면 모든 오브가 새 방향으로 다시 떨어지며 연쇄가 폭발합니다.

- **한 줄 소개**: "막혔을 때, 보드를 돌려버려라."
- **차별점**: 2048/뿌요류의 머지 + 보드 회전이라는 판 전체를 뒤집는 자원. 회전 횟수가 제한된 자원이라 "언제 돌릴지"가 실력의 핵심.
- **세션**: 1판 60~120초
- **타겟**: 출퇴근길에 짧게 즐기는 20~40대 캐주얼 퍼즐 유저

## 3. 코어 루프

```
오브 확인 → 열 선택해 드롭 → 중력 정착 → 3개 이상 연결 시 머지 → 연쇄 판정
   ↑                                                   ↓
   └──────── 회전 게이지 획득 / 회전으로 판 뒤집기 ←───────┘
```

1. 화면 하단에 다음 오브(숫자 1~3)가 보인다.
2. 원하는 열을 탭하면 오브가 그 열에 떨어진다.
3. 중력으로 정착 후, 같은 숫자가 상하좌우로 **3개 이상 연결**되면 합쳐진다.
4. 합쳐진 자리에 **숫자+1** 오브가 생기고 점수 획득. 다시 중력 → 추가 머지 → **연쇄(체인)**.
5. 연쇄 2 이상이면 **회전 게이지 +1** (최대 3).
6. 막히면 게이지를 1 써서 보드를 좌/우로 90° 회전 → 전부 다시 낙하 → 대형 연쇄.
7. 오브가 최상단 줄(데스라인)을 넘으면 게임 오버.

## 4. 상세 규칙

### 4.1 보드
- **7×7 정사각**. 회전 시 판 크기가 변하지 않도록 정사각으로 고정.
- 좌표계: `(row 0 = 최상단, col 0 = 최좌측)`
- **데스라인**: row 0. 정착이 끝난 시점에 row 0에 오브가 남아 있으면 게임 오버. row 1은 경고 색으로 표시.

### 4.2 오브
- 값 `v = 1, 2, 3, ...` (상한 없음). 표시는 숫자 + 고유 색 + 고유 아이콘(색약 대응).
- 생성 확률(초반): `v1 70% / v2 25% / v3 5%`
- 진행에 따라 보정: 보드 최대값이 `M`이면 생성 분포를 `max(1, M-3) ~ max(1, M-1)` 구간으로 서서히 이동. → 후반에 1이 쓰레기가 되는 문제 방지.

### 4.3 머지 판정 (정착 후 반복)
```
settle():
  1. 중력 적용 (모든 오브를 아래로 압축)
  2. 같은 값끼리 상하좌우 연결된 컴포넌트 탐색 (BFS)
  3. 크기 >= 3 인 컴포넌트가 없으면 종료
  4. 각 컴포넌트를 "중력 방향 기준 가장 아래+왼쪽 칸"으로 합침 → 값 +1
     점수 += 2^(새 값) × 컴포넌트 크기 × chain
  5. chain += 1 → 1번으로 복귀
```
- 동시에 여러 컴포넌트가 성립하면 같은 chain 단계에서 함께 처리(연출도 동시).
- chain은 드롭/회전 1회 액션 단위로 초기화.

### 4.4 회전
- 조작: 화면 하단 좌/우 회전 버튼 또는 보드 위 좌/우 스와이프.
- 비용: **회전 게이지 1** (시작 1개, 최대 3개, 연쇄 2 이상 달성 시 +1).
- 처리: 보드 배열을 90° 회전(내용만 회전, 화면 방향과 중력은 항상 아래로 유지) → `settle()` 실행.
- 회전으로 인한 머지 연쇄에도 게이지가 충전되므로, 잘 쌓아두면 회전이 회전을 부른다.
- 게이지 0이면 회전 버튼 비활성(시각적으로 명확히 표시).

### 4.5 압박 요소 — 석화 타일
- 12번째 드롭마다 무작위 열의 최하단 빈 칸에 **석화 타일** 1개 생성.
- 머지 불가, 낙하는 함. 인접 칸에서 머지가 일어나면 파괴.
- 회전해도 사라지지 않아 판을 점점 좁힌다 → 장기전 방지 및 난이도 곡선 담당.

### 4.6 게임 오버
- 정착 완료 시점에 row 0 점유 → 게임 오버.
- 결과 화면: 점수 / 최대 연쇄 / 최고 오브 값 / 개인 최고 기록 갱신 여부 / 공유 버튼 / 다시하기.

## 6. UX / 화면 설계

### 6.1 세로 모드 전용 레이아웃 (가로는 회전 안내 표시)
```
┌──────────────────────┐
│  점수 12,340   연쇄 x3│  ← 상단 HUD (고정, safe-area 적용)
│  ◆◆◇  회전 게이지 2/3 │
├──────────────────────┤
│                      │
│      7 × 7 보드       │  ← 화면 중앙, 정사각. 한 변 = min(width-32, height*0.58)
│                      │
├──────────────────────┤
│  NEXT [3]            │
│  ⟲ 회전        회전 ⟳ │  ← 엄지 도달 영역(하단 25%)에 배치
└──────────────────────┘
```
- 조작 요소는 전부 **하단 1/3**에 배치(한 손 엄지 도달 범위).
- 왼손/오른손 모드 설정으로 버튼 좌우 반전 제공.
- 드롭은 보드 아무 열이나 탭. 드래그하면 낙하 미리보기(고스트) 표시 후 손 떼면 확정, 보드 밖으로 빼면 취소.

### 6.2 온보딩
- 튜토리얼 화면 없음. **첫 판을 튜토리얼로 사용**한다.
- 1번째 드롭: 열 위에 손가락 아이콘 힌트. 3번째 머지 성공 후: "보드를 돌려보세요" 회전 버튼 강조 1회.
- 모든 힌트는 1회성이며 즉시 스킵 가능.

### 6.3 피드백
- 머지: 스케일 팝 + 파티클 8개 이하(저사양 고려), 연쇄마다 음정 상승.
- 회전: 보드 전체 90° 트윈 애니메이션 220ms(이 동안 입력 잠금).
- 햅틱: `navigator.vibrate` 지원 기기에서 머지 10ms / 게임오버 60ms. 설정에서 끄기 가능. (iOS 미지원 → 없는 대로 동작)

## 7. 기술 설계

### 7.1 스택
- **TypeScript + Vite** (번들 최소화, 프레임워크 없음)
- **Canvas 2D** 단일 캔버스 렌더링 (DOM 리플로우 회피). WebGL 불필요.
- 상태 관리: 순수 함수형 게임 상태 + 명시적 상태 머신 (`title / playing / animating / paused / gameover`)
- 오디오: Web Audio API, 첫 터치 제스처에서 `AudioContext.resume()` 언락
- 저장: `localStorage` (최고 기록, 설정, 진행 중 판 스냅샷)
- **PWA**: manifest + Service Worker(precache) → 오프라인 플레이, 홈 화면 추가

### 7.2 디렉터리 구조(예정)
```
src/
  core/        # 순수 게임 로직 (DOM 의존 없음, 유닛 테스트 대상)
    board.ts       # 격자, 중력, 회전
    merge.ts       # 컴포넌트 탐색 및 머지 해석
    rng.ts         # mulberry32 결정론적 난수
    game.ts        # 상태 머신, 점수, 게임오버 판정
  render/      # Canvas 드로잉, 애니메이션 트윈
  input/       # Pointer Events → 게임 액션 변환
  ui/          # HUD, 결과 화면, 설정
  audio/
  pwa/
tests/         # core 로직 유닛 테스트 (Vitest)
```

### 7.3 결정론 (데일리 모드의 전제)
- `mulberry32(seed)` 사용. `seed = hash("YYYY-MM-DD" + mode)`.
- 게임 로직은 **부동소수점 미사용, 정수 격자 연산만** → 모든 기기에서 동일 결과 보장.
- 렌더링 난수(파티클 등)는 별도 RNG 인스턴스로 분리 (게임 시드 오염 방지).

### 7.4 성능 예산
| 항목 | 목표 |
| --- | --- |
| 초기 전송량 | gzip 300KB 이하 (JS 120KB 이하) |
| First Playable | 3G Fast 기준 3초 이내 |
| 프레임 | 2019년형 보급 안드로이드에서 60fps 유지 |
| GC | 게임 루프 내 신규 객체 할당 0 (파티클·좌표 객체 풀링) |
| 캔버스 해상도 | `min(devicePixelRatio, 2)` 로 상한 |

### 7.5 모바일 웹 필수 처리 (놓치면 바로 티나는 것들)
- `touch-action: none`, `user-select: none` — 스크롤/확대/텍스트 선택 차단
- `overscroll-behavior: none` — 당겨서 새로고침 방지
- iOS `100vh` 문제 → `visualViewport` + `dvh` 병행 사용
- `env(safe-area-inset-*)` — 노치/홈 인디케이터 영역 회피
- Pointer Events 사용 (마우스/터치 통합, 300ms 지연 없음)
- `visibilitychange` → 백그라운드 진입 시 rAF 정지 및 자동 일시정지, 복귀 시 상태 복원
- 저전력 모드/저사양 감지 시 파티클·화면 흔들림 자동 축소
- Service Worker 버전 갱신 시 "새 버전 준비됨" 토스트 후 재적용

### 7.6 접근성
- 색 + **숫자 + 도형 아이콘** 3중 구분 (색약 대응). 색약 프리셋 팔레트 제공.
- 최소 터치 타겟 44×44pt
- `prefers-reduced-motion` 존중 → 화면 흔들림/파티클 제거
- 한국어/영어 문자열 분리(i18n JSON)

| M5 출시 준비 | ✅ PWA(오프라인), 아이콘, 번들 gzip 17KB. **실기기 테스트는 미실시** |
| M6 랭킹 서버 | ⬜ 미착수 (선택 범위) |

남은 작업: 실기기 매트릭스 테스트(§9), 관찰 테스트를 통한 회전 훅 검증, 그리고 그 결과에 따른 밸런스 튜닝(회전 게이지 비용, 석화 타일 주기, 오브 생성 분포).

M0 종료 시점에 "이게 재미있는가"를 판단하고, 재미가 없으면 회전 규칙(비용·방향·범위)만 바꿔 재검증합니다. 이 판단 전에는 아트/사운드에 시간을 쓰지 않습니다.

## 9. 검증 계획

- **유닛 테스트(Vitest)**: `core/` 전부 — 중력, 회전 불변식, 머지 해석, 연쇄 점수, 게임오버 조건, 동일 시드 재현성.
- **골든 리플레이 테스트**: 입력 시퀀스 → 최종 점수 스냅샷 비교. 로직 변경 시 회귀 감지.
- **실기기 매트릭스**: iPhone SE2(작은 화면) / iPhone 14 Pro(노치·다이내믹 아일랜드) / 갤럭시 A 시리즈(저사양) / 갤럭시 S 최신 / iPad Safari.
- **첫 세션 관찰 테스트**: 5명에게 아무 설명 없이 링크만 전달, 60초 내에 회전 기능을 스스로 발견하는지 관찰.
