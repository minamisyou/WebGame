## 요약

**GRAVITON** — 7×7 격자에 숫자 오브를 떨어뜨려 같은 숫자 3개 이상을 합치는 퍼즐.
막혔을 때 보드 전체를 90° 회전시켜 전부 다시 떨어뜨리는 것이 핵심 훅.

- 조작: 탭(드롭) + 좌우 스와이프(회전) — 한 손 엄지로 완결
- 1판 60~120초, 오프라인 동작(PWA), 데일리 시드 공유
- 스택: TypeScript + Vite + Canvas 2D, 엔진 없음
